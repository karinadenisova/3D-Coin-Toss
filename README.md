🪙 3D Coin Toss — брось монету в трёхмерной симуляции

> «Орёл или решка? Смотри на 3D-монету в консоли»

**3D Coin Toss** — это набор консольных утилит для симуляции броска монеты с трёхмерным ASCII-эффектом.  
Монета вращается в 3D-пространстве, демонстрируя анимацию полёта, и показывает результат — орёл или решка.

## 🚀 Особенности
- 🪙 3D-анимация вращения монеты в консоли (псевдо-3D через ASCII).
- 🌀 Эффект движения: монета подлетает, вращается и приземляется.
- 🎨 Подсветка результата: орёл — зелёный, решка — красный.
- ⚡ Быстрая анимация: 1-2 секунды на бросок.
- 📊 Подсчёт статистики: сколько раз выпал орёл/решка.
- ⌨️ Интерактивный режим: нажимайте Enter для нового броска.
- 🎯 Выбор количества одновременных бросков (где реализовано).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python coin_toss.py`                   |
| Go         | стандартная библиотека               | `go run coin_toss.go`                   |
| JavaScript | Node.js (без внешних модулей)        | `node coin_toss.js`                     |
| Java       | стандартная библиотека               | `javac CoinToss.java && java CoinToss`  |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand`, `colored` (crates)           | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby coin_toss.rb`                     |
| PHP        | стандартная библиотека               | `php coin_toss.php`                     |
